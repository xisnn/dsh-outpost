# 真机验证清单（v0.8.0）

> 为什么需要这份清单：v0.5.4 → v0.8.0 这几个版本改的都是「用户能直接感知」的东西
> （图片显示、边缘手势、系统通知、文档查看、会话搜索），但一直都是**在模拟器上验证的**。
> 模拟器跟真机有几处关键差异：手势导航的实现、通知权限与厂商 ROM 的拦截、
> GPU 渲染路径、内存限制（大文档解析）。这些都恰好在新功能的影响范围内。

## 准备

**装哪个包**：GitHub Actions 里「Android APK」这个 workflow 的产物（artifacts）。
找 tag 为 `v0.8.0` 的那次运行，下载 `app-debug.apk` 或 release 包。

**覆盖安装注意**：如果之前装过旧版本，直接覆盖可能报
`INSTALL_FAILED_VERSION_DOWNGRADE`。遇到就先卸载再装（会话列表不会丢，
数据在电脑上；手机上要重新配对一次）。

> **重要**：卸载重装后，**通知权限会重置**，首次启动会重新弹「允许通知」。
> 如果不小心点了「不允许」，去「设置 → 应用 → DSH Pocket → 通知」手动打开，
> 否则第三部分的检查都会失败。

**前置条件**：

- [ ] 电脑上 DSH 已启动，且绑的是局域网 IP（不是 127.0.0.1）
- [ ] 手机和电脑在同一个 Wi-Fi
- [ ] 记下启动日志里的 `token=`（配对要用）

## 已知的、不用报的问题

- **App 被系统杀掉后收不到通知** —— 这是本地通知的固有边界。要真正做到
  杀进程也能收，得接厂商推送通道（小米/华为/OPPO 各自的 SDK），工作量很大。
- **图片首次加载有几秒等待** —— 图片是完整下载到本地再显示，2 MB 的图在
  局域网上大概 1-2 秒。还没有做渐进式加载。
