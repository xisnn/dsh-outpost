# v0.18.1 修复记录

## 公网审批通道

审批 WebSocket 复用已登录服务的主机、端口和 TLS，路径为 `/ws/mobile`。
首次配对显式发送 `publicUrl`；已有设备凭据重连时也使用同一入口，避免回退到
公网不可达的 3081 端口。服务端候选地址必须与登录入口同源且安全级别一致。

React Native 0.81.4 的默认 URL 没有字段 setter，也无法正确解析 WebSocket
主机。审批模块显式使用 `whatwg-url-without-unicode`，防止把审批连接发到网站
根路径而产生 502。未改变全局 URL，也未降低认证要求。

回归测试加载真实 RN URL 源码，使用生产 Babel 配置编译审批客户端，覆盖首次
配对、已有授权重连、TLS、端口和 IPv6。已通过公网隧道验证配对和重连，修复包
亦已完成 Android 手机人工验证。

## 桌面网络修复

一键修复会停止经身份核对的旧 DSH Web 进程，再绑定当前有效网卡地址启动服务，
确认可访问后恢复原来运行的隧道。桌面等待时间与后台修复流程一致，错误提示保留
在界面上；服务未启动或地址失效时不展示可配对二维码。
